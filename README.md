# credit-card-customer-analytics 

Project Overview
This project involves a comprehensive data analytics and business intelligence solution developed to analyze credit card customer behaviors, predict churn risks, and simulate revenue-generating strategies.

Tech Stack & Tools
* **Data Engineering & Cleaning:** Advanced Excel (Power Query logic, IF/IFS, XLOOKUP)
* **Automation:** VBA Macros (One-click refresh & dynamic formatting)
* **Data Visualization:** Excel Dashboards (Combo Charts, Stacked Bars) & Power BI (Phase 2)
* **Strategic Presentation:** PowerPoint (Data Storytelling & Morph Transitions)

📊 Key Highlights
1. **Data Hygiene:** Handled null incomes, corrected negative credit limits, and treated anomalous age records.
2. **Customer Segmentation:** Built a 5-Tier algorithmic model (VIP, Potential, Regular, At-Risk, Passive).
3. **Predictive Scenarios:** Utilized Goal Seek and Data Tables to simulate the impact of credit limit adjustments on transaction volumes.
4. **Pareto 80/20 Analysis:** Identified core card categories driving the majority of transaction revenues.
